连接您的音乐空间

上传 / 删除音乐需要 GitHub 访问令牌。
令牌仅保存在当前这台设备的浏览器中，不会上传到任何服务器。

如何获取令牌？（还没有 GitHub 账号？点这里看步骤）
  1. 用电脑或手机浏览器打开 github.com，注册账号并登录（免费）。
  2. 点击右上角头像 → Settings → Developer settings → Personal access tokens → Tokens (classic)。
  3. 点 Generate new token (classic)，Expiration 选 90 天即可，只勾选 public_repo 一项。
  4. 拉到最下面点 Generate token，复制 ghp_ 开头的令牌，粘贴到上面输入框。
