# 悦音 · 音乐网站

一个简洁大气的音乐网站：**音频播放器式首页** + **密码后台管理**，免注册、直接下载，手机电脑都好用。

## 功能一览

| 功能 | 前台（访客） | 后台（管理员，需密码） |
| --- | --- | --- |
| 在线试听 | ✅ 全部四个栏目 | ✅ |
| 下载 | ✅ 背景音乐 / 女声 / 男声 | ✅ 全部栏目 |
| 客户音乐下载 | ❌ 仅试听（显示联系提示） | ✅ |
| 上传 / 删除 | ❌ 无任何入口 | ✅ 分栏目上传、删除 |

- 首页四个栏目：**客户音乐 / 背景音乐 / 女声 / 男声**
- 底部悬浮播放器：播放/暂停、上一首/下一首、进度条拖动、正在播放动效
- 大号下载按钮，带实时下载进度
- 免注册、免登录，打开即听、点击即下
- 手机自适应（响应式布局 + 底部播放条）

## 一、本地预览（可选）

需要电脑安装 [Node.js](https://nodejs.org/zh-cn)（官网下载安装即可）。在项目文件夹打开终端：

```
node dev-server.mjs
```

然后浏览器打开 `http://localhost:8080`（首页）、`http://localhost:8080/admin.html`（后台，默认密码 `admin888`）。

## 二、上线部署（免费空间，国内可访问）

网站采用 **GitHub 仓库作为免费空间**，通过 **jsDelivr CDN** 在国内高速访问。只需三步：

### 第 1 步：注册 GitHub 账号（免费）

打开 <https://github.com> → 右上角 **Sign up** → 按提示用邮箱注册并验证。

### 第 2 步：生成访问令牌（相当于“上传钥匙”）

1. 登录 GitHub，点右上角**头像** → **Settings**
2. 左侧最下面 **Developer settings** → **Personal access tokens** → **Tokens (classic)**
3. 点 **Generate new token (classic)**：
   - Note 随便填（如 `music`）
   - Expiration 建议选 90 天或 No expiration
   - 只勾选 **public_repo**（勾上它会自动勾选下面几个子项，正常）
4. 拉到最下面点 **Generate token**，复制 `ghp_` 开头的令牌（只显示一次，先粘贴保存到记事本）

### 第 3 步：运行一键部署脚本

```
npm run deploy
```

按提示输入：令牌（粘贴时屏幕不显示，属正常）、仓库名（如 `music`）、后台密码、网站名称。脚本会自动：创建公开仓库 → 上传网站 → 启用 GitHub Pages → 输出网址。

部署完成后会显示两个网址：

- **国内推荐**：`https://cdn.jsdelivr.net/gh/你的用户名/仓库名@main/index.html`
- **备用域名**：`https://你的用户名.github.io/仓库名/`

后台管理地址 = 上面的地址把 `index.html` 换成 `admin.html`。

## 三、日常使用

### 前台（访客视角）
打开首页链接即可。**客户音乐**栏目只能试听；**背景音乐/女声/男声**可试听 + 点大按钮直接下载。无需注册登录。

### 后台（你自己）
1. 打开后台网址 → 输入管理密码进入
2. 首次使用会要求粘贴 GitHub 令牌（第 2 步生成的那个），**仅保存在你自己电脑的浏览器里**
3. 上传：选文件 → 填曲目名称 → 选栏目（背景音乐/女声/男声/客户音乐）→ 点“上传到「XX」”，带进度条
4. 删除：点列表里的红色“删除”按钮，二次确认后删除（前台同步消失）
5. “设置”里可以：修改本机后台密码、更新令牌
6. 手机上也能管理：手机浏览器打开后台网址，输入密码后（换设备需重新粘贴令牌）即可上传/删除

### 分享给客户
把首页链接发给客户即可。演示用的两首“演示曲”可在后台上传真实音乐后删除。

## 四、重要说明（请务必阅读）

1. **免费方案的代价——仓库公开**：GitHub 免费公开仓库 + 免费 CDN 才无需备案、国内可访问。“客户音乐”栏目在**前台隐藏了下载按钮**，但懂得技术的人仍可通过浏览器抓包等方式拿到文件直链。**重要、私密的文件请不要上传**，客户音乐建议只传小样。
2. **单文件 ≤ 19MB**：jsDelivr 免费 CDN 单文件上限 20MB。建议上传 MP3（320kbps 的 5 分钟歌曲约 12MB，足够用）。
3. **列表更新有缓存**：上传/删除后，jsDelivr 会有几分钟缓存延迟，刷新几次或稍等即可。新上传的文件本身是新的网址，立即生效。
4. **国内访问**：建议使用 jsDelivr 链接（`cdn.jsdelivr.net/gh/...`）；`用户名.github.io` 链接在部分网络下可能打不开或较慢，作为备用。
5. **令牌安全**：令牌只保存在你自己的浏览器里。如果泄露或忘记，到 GitHub 重新生成一个，再到后台“设置”里更新即可（旧令牌可删除）。
6. **修改网站名称/联系提示**：直接编辑 GitHub 仓库里的 `assets/config.js` 文件（网站名 `siteName`、联系提示 `contact`），或在本地改完后重跑部署脚本。

## 五、常见问题

**Q：上传失败提示“令牌无效或已过期”？**
A：令牌过期（Expiration 选了 90 天）或复制不全。重新生成令牌，在后台“设置”里更新。

**Q：上传成功但首页看不到？**
A：等 1~2 分钟（CDN 缓存）后刷新。也可以上传后点开对应栏目刷新一次。

**Q：能上传 19MB 以上的音频吗？**
A：免费方案不支持。可压缩音质（MP3 192~256kbps），或将来换收费空间。

**Q：换电脑后后台进不去？**
A：新设备需要重新输入密码和令牌（数据都存在 GitHub，不会丢）。

**Q：想用自己的域名？**
A：可购买域名后在 GitHub 仓库 Settings → Pages 里绑定，或在 README 末尾联系技术支持。
